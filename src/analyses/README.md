# `src/analyses/`

This directory held the authors' replication package. The package was removed from the
repository on 2026-09-15: it is the authors' published work, and every job in
`src/stata/` cites it by original file name and line number (`Source :` in each header).

- **Original package**: Kanas, A., & Kosyakova, Y. (2022), replication files on OSF,
  **https://doi.org/10.17605/OSF.IO/XZ3V5** (`00011`–`00024*.do`, `config.do`,
  `_PROJECT_MASTER_.do`, `macro_orig/`). Two data files it needs but does not ship,
  `macro_orig/Melitz_Toubal_proxling/{ling_web,proxling}.dta`, come from
  [CEPII](https://www.cepii.fr/CEPII/en/bdd_modele/bdd_modele_item.asp?id=19).
- **`authors_package_fixes.diff`**: the only edits made to that package, as a
  `git apply`-able patch against the OSF files (verified to apply cleanly). All are
  environment fixes (paths, Stata/BE's variable cap, one deprecated command), none
  analytical; each is explained in `docs/lab_notebook.md`, "Known
  replication-environment fixes".

## `remote/jobs/`: the county-year panel transfer (22 jobs)

The treatment variable (local supply of integration courses) is built by the authors'
`00011_data_macro.do` from public sources into `savedata/macro_data.dta`, 2,807
county-years. It has to be merged onto the SOEP microdata on DIW Berlin's SOEPremote
server, and SOEPremote accepts no attachments: the only route for external data is an
in-job `input … end` block, with a ceiling of roughly 200–250 lines per e-mail.

So the panel was encoded as scaled integers, split into 18 parts of at most 190 lines
(`10_supply_part1..18.do`) and sent by hand, then stacked (`11_supply_stack.do`), joined
with two SOEP-derived county variables that cannot be built locally
(`12_soepvars_remote.do`), assembled (`13_supply_assemble.do`) and checked against
`EXPECTED.txt` (`14_supply_check.do`). The result, `$mydata/msuemer/cty_supply.dta`
(2,807 × 16), is what `src/stata/remote/clean_county_merge.do` reads. The files keep
their original paths because the job e-mails and the lab notebook refer to them by name.
Full account: `remote/jobs/README.md`.

## `remote/tools/`: generators and pre-send checks

| File | Role |
|---|---|
| `preflight.py` | banned-token and non-ASCII scan of a job's send block; owns the `BANNED` list with the provenance of each learned token |
| `check_clipboard.py` | re-derives a job's payload checksum from the composed e-mail, catching truncation, altered digits and non-ASCII before sending |
| `make_supply_jobs.py` | generates the 22 supply jobs and `EXPECTED.txt` from `macro_data.dta` |
| `verify_payload.py` | decodes the supply jobs back and diffs them against the source |
| `make_partc_jobs.py` | generates `src/stata/remote/clean_citizenship*.do`, `clean_lingprox.do`, `clean_confounders.do` |
| `make_23_jobs.py` | generates `src/stata/remote/tab04_*`, `tab05_*`, `fig02_*` from the `tab03_employment.do` template |

Generated `.do` files carry `* GENERATED BY …` on line 1 and are not edited by hand.
`make_partc_jobs.py` and `make_supply_jobs.py` read the authors' files, so they only run
with the OSF package in place; `make_23_jobs.py` needs nothing beyond this repository.
All three were last run on 2026-09-15 and reproduced every generated job byte for byte.
